# The Skill Owns the Handoff Document

The plugin carries no copy of the handoff document's outline. On each compaction, it reads the installed `handoff` skill's `SKILL.md` and asks a fork to follow it with `handoff inline`. The filename's slug comes from the document's `# Handoff:` heading, and its time comes from the plugin's clock, because a fork can't read one: in the first probe it wrote `00:00`. The plugin tells the fork the current time so the document's timestamp line agrees. We chose this over a bundled template so that the manual handoff and the automatic one can never drift apart. The cost is that a change to the skill changes this plugin's output with no release here. The plugin rejects any reply that doesn't open with `# Handoff:` or that still carries the skill's file pointer. Its tests stub the skill, so a live check of the real skill waits on [#1](https://github.com/kendrick/handoff-on-compact/issues/1). The plugin repeats only the skill's folder rules, because a fork can't write files.
